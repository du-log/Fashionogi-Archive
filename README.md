# The Fashionogi Archive
**Site Version: 1.0**

**Disclaimer: As this website is still in the initial deployment phase, there may be bugs and design flaws.**

The Fashionogi Archive is a community-driven fashion lookbook and database built for the MMO Mabinogi.
It provides a centralized platform for players to upload, tag, and share their in-game outfits. 

This is currently a one-man project made with the sole purpose of being able to share our styles with our fellow Milletians.
After all, Fashionogi is the real endgame of Mabinogi.

My hope is that the Archive will successfully serve a niche in the Mabinogi community and provide an outlet for fashionistas in all regions where the game is available.

## Current Features
* User registration and access, with authentication provided by http-Only JWT.
* Style uploading and favoriting, with images saved in WebP format.
* Gallery for displaying all approved styles, with ability to filter based on style gender, race, username, style title, and tag.
* User profiles and private dashboard to view personally uploaded styles and favorites.
* User settings page, though currently minimal with only the ability to change your username.
* Basic news system for sharing any site news and updates.

## Roadmap
Below is the current feature roadmap for the future, in no particular order.
* Website UI Improvements.
* Follower System.
* Time-Window Trending Feeds.
* Extended Profile UI, if requested.
* User Avatars and custom Profile Banners.
* Site Themes.
* Custom titles and colored community names.
* Grouping outfits into shareable public collections.
* Email verification, password recovery, and OAuth (Discord/Google).
* Post-Editing Pipeline: Reverting edited live submissions to pending status for re-review.
* Deep Equipment Search: Direct queries for specific items.
